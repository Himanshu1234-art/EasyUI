Core HCI Principles

Understand the ideas behind the improved interfaces.

01

Affordance & signifiers

Controls should suggest how to use them. Buttons look clickable and labels make actions clear.

02

Visibility of system status

Keep users informed with confirmation, progress or clear feedback after an action.

03

Error prevention & recovery

Prevent common mistakes and give helpful instructions when errors occur.

04

Consistency & standards

Use familiar patterns, predictable labels and similar styles for similar actions.

05

Recognition over recall

Show options, labels and hints so people do not have to remember hidden commands.

06

Accessibility & inclusion

Support readable text, sufficient contrast, keyboard operation and understandable labels.

07

User control & freedom

People should be able to go back, cancel or correct unintended actions.

08

Feedback

Make it clear that an action was received and explain what happened next.

09

Responsive design

Layouts should adapt to mobile, tablet and desktop screens.

About the Study

Project scope, method and limitations.

Project overview

EasyUI — HCI Learning Lab is a frontend educational website demonstrating how interface decisions affect usability.

It presents five pairs of interface examples: sign-in, navigation, form validation, checkout and accessibility. Visitors can interact with controls, compare versions and submit a preference rating.

Objectives

  • Explain HCI concepts using practical examples.
  • Compare problematic and improved interface patterns.
  • Demonstrate feedback, validation, consistency and accessibility.
  • Collect simple in-session preferences for discussion.

Methodology

  1. Observe both interface versions.
  2. Try the interactive controls.
  3. Rate which version seems easier.
  4. Review the summary and discuss why.

Technology used

HTML CSS JavaScript

Limitations

This prototype does not run a controlled study automatically. Ratings are temporary and are not uploaded to a server. The examples are educational, not proof that all users will prefer one design.

Suggested usability test for classmates

Ask 5–10 volunteers to try each version. Give them the same task, such as finding the Help section or correcting a phone number. Record whether they succeed, time taken, mistakes and which version they prefer. Participation should be voluntary; do not collect passwords or sensitive information.

Usability Testing Mode

What is measured?

Effectiveness: whether the task was completed.

Efficiency: time taken to complete the task.

Errors: incorrect attempts while the task is active.

How to use it in your study

  1. Explain the task without giving away the steps.
  2. Ask the participant to think aloud if comfortable.
  3. Record the result and ask what felt confusing.
  4. Repeat with multiple volunteers and compare observations.

Why accessibility matters

Readable text: helps people who need larger text.

High contrast: makes text and controls easier to distinguish.

Reduced motion: limits animations and transitions.

These controls demonstrate a few accessibility options. They do not replace a complete accessibility audit or testing with people with disabilities.

HCI connection

Accessible design supports more people, gives users control over their experience and reduces barriers to completing tasks.
